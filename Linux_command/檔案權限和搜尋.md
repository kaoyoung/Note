# 檔案權限
### umask
```shell
umask
umask -S      # S stands for Symbolic
```

首先先想一下「檔案」和「目錄」的預設權限是什麼
- 對於檔案預設是 `-rw-rw-rw-`
- 對於目錄預設是 `drwxrwxrwx`
>因為檔案一般是放資料所以不需要執行權限，而目錄需要執行權限才能進入所以需要執行權限。

`umask` 的分數是指「**該預設值需要減掉的權限**」。
### chattr, lsattr
底下的chattr指令只能在Ext2/Ext3/Ext4的 Linux 傳統檔案系統上面完整生效， 其他的檔案系統可能就無法完整的支援這個指令了。

```shell
chattr [+-=][ai] file/directory
lsattr [-adR] file/directory
```
- a: 當設定 a 之後，這個檔案將只能增加資料，而不能刪除也不能修改資料，只有root 才能設定這屬性
- i: 這個 i 可就很厲害了！他可以讓一個檔案『不能被刪除、改名、設定連結也無法寫入或新增資料！』。  對於系統安全性有相當大的助益！只有 root 能設定此屬性

### SUID, SGID, SBIT
#### SUID
SUID有這樣的限制與功能:
- SUID 權限**僅對二進位程式(binary program)有效**；
- 執行者對於該程式需要具有 x 的**可執行權限**；
- 本權限僅在**執行該程式的過程中有效** (run-time)；
- 執行者將具有該程式**擁有者 (owner) 的權限**。
#### SGID
SGID 有如下的功能：
- SGID 對**二進位程式**有用；
- 程式執行者對於該程式來說，需**具備 x 的權限**；
- 執行者在執行的過程中將會獲得**該程式群組的支援**！
#### Sticky Bit
SBIT 目前只針對目錄有效，對於檔案已經沒有效果了。SBIT 對於目錄的作用是：
- 當使用者對於此目錄具有 w, x 權限，亦即具有寫入的權限時；
- 當使用者在該目錄下建立檔案或目錄時，僅有自己與 root 才有權力刪除該檔案
>例子: `/tmp` 目錄本身的權限是『drwxrwxrwt』

>[!Note] SUID/SGID/SBIT 權限設定
>- 4 為 SUID
>- 2 為 SGID
>- 1 為 SBIT
# 檔案搜尋
### which (尋找執行檔)
```shell
which [-a] command
which ifconfig
```
- a (all): 將所有由 PATH 目錄中可以找到的指令均列出，而不止第一個被找到的指令名稱

這個指令是根據『[PATH](https://linux.vbird.org/linux_basic/centos7/0220filemanager.php#dir_path)』這個環境變數所規範的路徑，去搜尋『執行檔』的檔名～ 所以，重點是找出『執行檔』而已
### whereis (由一些特定的目錄中尋找檔案檔名)
```shell
whereis [-bmsu] file/directory
whereis passwd
```
- b: 只找 binary 格式的檔案
- m: 只找在說明檔 manual 路徑下的檔案
- s: 只找 source 來源檔案
- u: 搜尋不在上述三個項目當中的其他特殊檔案

因為 whereis 只找幾個特定的目錄而已～並沒有全系統去查詢之故。所以說，whereis 主要是針對 /bin /sbin 底下的執行檔， 以及 /usr/share/man 底下的 man page 檔案，跟幾個比較特定的目錄來處理而已。

>想要知道 whereis 到底查了多少目錄？可以使用 whereis -l 來確認一下即可
### find

```shell
find [PATH] [option] [action]
```

1. 與時間有關的選項：共有 -atime, -ctime 與 -mtime ，以 -mtime 說明
   - -mtime  n ：n 為數字，意義為在 n 天之前的『一天之內』被更動過內容的檔案；
   - -mtime +n ：列出在 n 天之前(不含 n 天本身)被更動過內容的檔案檔名；
   - -mtime -n ：列出在 n 天之內(含 n 天本身)被更動過內容的檔案檔名。
   - -newer file ：file 為一個存在的檔案，列出比 file 還要新的檔案檔名
![[find command data parameter.png]]

```shell
find / -mtime 0
find /etc -newer /etc/passwd
```

2. 與使用者或群組名稱有關的參數：
   - -uid n ：n 為數字，這個數字是使用者的帳號 ID，亦即 UID ，這個 UID 是記錄在            /etc/passwd 裡面與帳號名稱對應的數字。這方面我們會在第四篇介紹。
   - -gid n ：n 為數字，這個數字是群組名稱的 ID，亦即 GID，這個 GID 記錄在 /etc/group，相關的介紹我們會第四篇說明～
   - -user name ：name 為使用者帳號名稱喔！例如 dmtsai 
   - -group name：name 為群組名稱喔，例如 users ；
   - -nouser    ：尋找檔案的擁有者不存在 `/etc/passwd` 的人！
   - -nogroup   ：尋找檔案的擁有群組不存在於 `/etc/group` 的檔案！當你自行安裝軟體時，很可能該軟體的屬性當中並沒有檔案擁有者，這是可能的！在這個時候，就可以使用 -nouser 與 -nogroup 搜尋。
```shell
find / -name passwd
find / -name "*passwd*"
find /run -type s
find / -perm /7000
```
