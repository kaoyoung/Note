## 拷贝构造函数 (Copy Constructor)
**深拷贝**创建对象的独立副本。其核心步骤包括：
1. 分配新资源（如内存）
2. 复制原对象数据（如逐元素复制数组）
3. 保持原对象状态不变
```c++
class String {
public:
    String(const String& other) {
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
    }
private:
    char* data;
};
```
## 移动构造函数 : 
移动构造函数通过**转移资源所有权**提升效率，直接接管原对象资源并置空其指针，避免深拷贝开销。其核心步骤包括：
1. 接管原对象资源（如指针）
2. 将原对象指针置为`nullptr`
3. 原对象进入无效状态（仅保证可析构）
```cpp
class String {
public:
    String(String&& other) noexcept {
        data = other.data;
        other.data = nullptr;
    }
private:
    char* data;
};
```
## 参数类型与语法对比
|造函数类型|参数类型|用途说明|
|---|---|---|
|拷贝构造函数|`const T&`|绑定左值，确保不修改原对象|
|移动构造函数|`T&&`|绑定右值，优化临时对象处理|
## 移动构造函数的典型场景
- 用临时对象初始化新对象：
```cpp
MyClass obj = MyClass();  // 调用移动构造
```
- 显式使用`std::move`：
```cpp
MyClass obj1;
MyClass obj2 = std::move(obj1);  // 调用移动构造
```

## 示範
```cpp
#include <iostream>
#include <utility>
#include <cstring>

class ResourceHolder {
public:
    // 普通构造
    ResourceHolder(const char* str) {
        data = new char[strlen(str) + 1];
        strcpy(data, str);
        std::cout << "构造: " << data << std::endl;
    }

    // 拷贝构造（深拷贝）
    ResourceHolder(const ResourceHolder& other) {
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
        std::cout << "拷贝构造: " << data << std::endl;
    }

    // 移动构造（转移资源）
    ResourceHolder(ResourceHolder&& other) noexcept {
        data = other.data;
        other.data = nullptr;
        std::cout << "移动构造: " << (data ? data : "空") << std::endl;
    }

    ~ResourceHolder() {
        if (data) {
            std::cout << "析构: " << data << std::endl;
            delete[] data;
        }
    }

private:
    char* data;
};

int main() {
    ResourceHolder r1("Hello");          // 构造
    ResourceHolder r2 = r1;              // 拷贝构造
    ResourceHolder r3 = ResourceHolder("World");  // 临时对象 → 移动构造
    ResourceHolder r4 = std::move(r1);   // 显式移动构造
    return 0;
}
```
