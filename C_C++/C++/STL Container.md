# `priority_queue`
#### 參考自[C++ priority_queue(STL) 用法與範例](https://notes.boshkuo.com/docs/C++/STL/priority_queue)、[Priority Queue in C++ STL](https://www.geeksforgeeks.org/cpp/priority-queue-in-cpp-stl/)
## 用途
`priority_queue` 中的元素是自動按照某種排序準則(**默認為由大到小**)組織的。每次從 **priority_queue** 取出一個元素時，將**取出目前最高優先權的元素**。
- 時間複雜度$O(\log n)$
---
## 初始化
1. 創建一個空的**max heap**
```c++
#include <queue>
using namespace std;

priority_queue<int> maxHeap;
```
- time complexity : $O(1)$

2. 利用現有vector創建**max heap**
```c++
#include <queue>
#include <vector>
using namespace std;

vector<int> nums = {10, 20, 30, 5, 15};
priority_queue<int> maxHeap(nums.begin(), nums.end());
```
- time complexity : $O(n)$

3. 使用自定義比較器建立**max heap**
```c++
#include <queue>
using namespace std;

struct MaxHeapComparator{
	bool operator()(int lhs, int rhs){
		return lhs < rhs;
	}
}

priority_queue<int, vector<int>, MaxHeapComparator> maxHeap;
```

>這邊的(lhs, rhs)可以思考成(已在`priority_queue`的值, 要加入的值)，所以operator()的操作可想成加入的值大於`priority_queue`的值就回傳true，這表示加入的值優先值較大；另一方面`priority_queue`是由優先值由大到小排列。和在一起看就是`max_heap`。

`std::priority_queue`的定義要三個參數
- 資料型別 (`int`)
- 容器型別 (`std::vector<int>`)
- 比較器型別 (Compare)

**為何這邊比較式呼叫型別，而非函式 ?**
>因為編譯器在編譯時期就知道確切的型別（包含 Lambda 裡面的程式碼），它可以把 `lhs < rhs` 這行比較邏輯，直接**複製貼上 (Inline)** 到 `priority_queue` 或 `std::sort` 的內部迴圈裡。
>>**結果：** 完全沒有函式呼叫的開銷。比較的動作就像是你直接在 `while` 迴圈裡寫 `if (a < b)` 一樣快。

```c++
#include <queue>
#include <vector>
using namespace std;

auto comparator = [](int lhs, int rhs) { return lhs < rhs; };
std::priority_queue<int, std::vector<int>, decltype(comparator)> maxHeap(comparator);
```

what's the type of lambda expression
- The type of a lambda expression is a **unique, unnamed class** generated by the **compiler**. In C++ terminology, this is called the **Closure Type**.
For example, if you write
```c++
auto comparator = [](int lhs, int rhs){
	return lhs < rhs;
};
```
When the compiler sees that lambda, it secretly generates a class that looks something like this:
```c++
// The compiler invents a random, unique name for the class
class __lambda_12ab34cd {
public:
    // It overloads the () operator to make it callable like a function
    bool operator()(int lhs, int rhs) const {
        return lhs < rhs;
    }
};
```

4. 創建**min heap**
```c++
#include <queue>
#include <vector>
using namespace std;

priority_queue<int, vector<int>, greater<int>> minHeap;
```

細看greater函式
```c++
template <class T> struct greater {
  bool operator() (const T& x, const T& y) const {return x>y;}
  typedef T first_argument_type;
  typedef T second_argument_type;
  typedef bool result_type;
};
```

5. 利用現有 vector 創建 **min heap**
```c++
#include <queue>
#include <vector>
using namespace std;

vector<int> nums = {10, 20, 30, 5, 15};
priority_queue<int, vector<int>, greater<int>> minHeap(nums.begin(), nums.end());
```
