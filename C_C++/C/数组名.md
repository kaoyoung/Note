# 觀念
在 C/C++ 中，當你聲明一個數組時，例如 `int myArray[5];` ，這個數組名 `myArray` **代表著數組在計算機內存中起始位置的地址** ，而這位置是一個常量。
## 數組和指針的差
- **指針變量 (`int *p`)：** 是一個 **變量**。它在記憶體中佔用空間（例如 8 bytes），用來存儲一個地址。因為它是變量，所以你可以隨時修改它存儲的內容（也就是改變它指向哪裡）。    
- **數組名 (`int a[]`)：** 是一個 **符號常數**。它本身在執行期間 **不佔用額外的記憶體空間** 來存儲地址。    
    - 在編譯後，所有出現 `a` 的地方，都會直接被替換成該數組在記憶體中的偏移量（Offset）或絕對地址。        
    - 既然它不是一個存儲地址的「變量」，自然就沒有地方讓你去「賦值」改變它。
# 為甚麼要這樣做
1. 數組占用連續空間，所以只要開始位置跟間隔大小就可以表達，但要小心不要找過頭。
2. **常量的優勢：** 如果 `起始地址` 是固定的（常量），編譯器可以對這段代碼進行極大的優化，生成最精簡的組合語言指令。
# 限制
無法使用=來賦值。以下為錯誤例子
```C
int array1[5] = {0};
int array2[5] = array1; //數組不能用=賦值
```
如果允許`array2 = array1` ，會有歧異
1. 你是指派一個地址
2. 把array1的內容拷貝給array2
