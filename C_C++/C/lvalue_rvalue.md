# 簡單的定義
- **左值 (lvalue, locator value)** 表示了一个占据内存中某个可识别的位置（也就是一个地址）的对象。
- **右值 (rvalue)** 则使用排除法来定义。一个表达式不是 **左值** 就是 **右值**。 那么，右值是一个 **不** 表示内存中某个可识别位置的对象的表达式。
### 例子
```c
int var;  
var = 4;
4 = var;       // 错误！  
(var + 1) = 4; // 错误！
```
**原因** : 常量 `4` 和表达式 `var + 1` 都不是左值，都是表达式的临时结果，而没有可识别的内存位置，所以賦值給他們是毫無意義。

```c
int foo() {return 2;}  
int main()  
{  
    foo() = 2;  // error: lvalue required as left operand of assignment
    return 0;  
}
```

**函數回傳可賦值**的例子 : 
```c
int globalvar = 20;  
int& foo()  
{  
    return globalvar;  
}  
  
int main()  
{  
    foo() = 10;  
    return 0;  
}
```
**原因** : `foo` 返回一个引用。
使用場景 : 重载方括号操作符 `[]`，来实现一些查找访问的操作
```c
std::map<int, float> mymap;  
mymap[10] = 5.6;
```
**原因** : `std::map::operator[]` 的重载返回的是一个可赋值的引用。

# 可修改的左值
ISO C 加入 `const` 关键字后，左值可賦值的性質受到挑戰。
```c
const int a = 10; // 'a' 是左值  
a = 10; // 但不可以赋值给它！
```
**解法** : 不是所有的左值都可以被赋值。可赋值的左值被称为 **可修改左值 (modifiable lvalues)**。
>可修改左值是特殊的左值，**不含有数组类型、不完整类型、const 修饰的类型**。如果它是 `struct` 或 `union`，它的成员都（递归地）不应含有 const 修饰的类型。

# 左值与右值间的转换
```c
int a = 1; // a 是左值  
int b = 2; // b 是左值  
int c = a + b; // + 需要右值，所以 a 和 b 被转换成右值  
// + 返回右值
```
除了数组、函数、不完整类型的所有左值都可以转换为右值。
右值**不能**转换为左值，但右值可以通过一些更显式的方法产生左值。
```c
int arr[] = {1, 2};  
int* p = &arr[0];  
*(p + 1) = 10; // 正确: p + 1 是右值，但 *(p + 1) 是左值
```
相反來說
```c
int var = 10;  
int* bad_addr = &(var + 1); // 错误: 一元 '&' 操作符需要左值参数，左值的位置才有意義  
int* addr = &var; // 正确: var 是左值  
&var = 40; // 错误: 赋值操作的左操作数需要是左值
```
**思考想法** : 左值的位置才有意義，右值只是臨時產生的東西，位置沒意義。
