>[!question] 動機問題
>對於任一 **布林函數 (Boolean function)** $f: \{0, 1\}^n \to \{0, 1\}$，是否皆能由 **AND、OR、NOT** 組成的 **邏輯運算式 (Logic expression)** 來表達？換言之，該運算子集合是否具備 **功能完備性 (Functional Completeness)**？

>我們令這個邏輯運算式 (Logic expression) 為 $L: \{0,1\}^n \to \{0,1\}$ 。

>[!motivation]
>輸出就兩個可能的值 0 或 1 ，那我們可不可能把原輸出為 1 的原輸入整理成一類，只要符合這一類的一律輸出 1 ，而不符合得都輸出為 0 。同理，我們可不可能把原輸出為 0 的原輸入整理成一類，只要符合這一類的一律輸出 0 ，而不符合得都輸出為 1。

>[!observation] 觀察一  : 且運算和或運算的差別
>- 且運算 : 如果只要有一個元素為 0 結果就要為 0 ，且全元素為 1  結果就要為 1 ，那就應該用且運算。
>- 或運算 : 如果只要有一個元素為 1 結果就要為 1 ，且全元素為 0  結果就要為 0 ，那就應該用或運算。
# 積項之合 (sum of product , SOP)

>[!Motivation]
>把原輸出為 1 的原輸入整理成一類，只要符合這一類的一律輸出 1 ，而不符合的都輸出為 0 。

>[!thinking logic] 思考鍊
>你只要輸入一個 $x \in \{0,1\}^n$  且 $f(x) = 1$，在 $L(x)$ 之後要輸出為 1 ，那一個很自然的思路是把所有 $S_1 = \{t \in  \{0,1\}^n \  | \ f(t) = 1 \}$  中的元素在 $L$ 中都映射到 1 ，同時對於 $S_2 = \{t \in  \{0,1\}^n \  | \ f(t) = 0 \}$ 的情況，要確保在 $L$ 的建構中讓 $S_2$ 輸出 0 就好，所以一個很自然的想法是用**或運算**把這些都串起來。需注意**或運算**串起來的是原輸入 $x = \{x_1, \cdots, x_n\} \in \{0,1\}^n$ 在 $f$ 下映射的結果，還必須要把這個 $f$ 給模仿出來， $f$ 的特性是和原輸入完全符合輸出 1 (這邊可以用 NOT 運算把 0 扳成 1)，那就是和原輸入的 $x_i$ 一樣時輸出 1，再用**乘運算**串起來。

最小項 (minterm) : 在有 $n$ 個變數的布林函數中，一個**包含所有變數**的**乘積項 (AND term)**，就稱為最小項。每個變數都必須出現恰好一次（可以是原變數 $x$，也可以是反相變數 $\overline{x}$）。即找輸出為 **1** 的組合，用 **AND** 連起來（$1$ 是原貌，$0$ 是補項）。

# 合項之積 (product of sum, POS)

>[!Motivation]
>把輸出為 0 的情況整理成一類，只要符合這一類的一律輸出 0 ，而不符合的都輸出為 1 。

>[!thinking logic] 思考鍊
>你只要輸入一個 $x \in \{0,1\}^n$  且 $f(x) = 0$，在 $L(x)$ 之後要輸出為 0 ，那一個很自然的思路是把所有 $S_1 = \{t \in  \{0,1\}^n \  | \ f(t) = 0 \}$  中的元素在 $L$ 中都映射到 0 ，同時對於 $S_2 = \{t \in  \{0,1\}^n \  | \ f(t) = 1 \}$ 的情況，要確保在 $L$ 的建構中讓 $S_2$ 輸出 1 就好，所以一個很自然的想法是用**乘運算**把這些都串起來。需注意**乘運算**串起來的是原輸入 $x = \{x_1, \cdots, x_n\} \in \{0,1\}^n$ 在 $f$ 下映射的結果，還必須要把這個 $f$ 給模仿出來， $f$ 的特性是和原輸入完全符合輸出 0 (這邊可以用 NOT 運算把 1 扳成 0)，那就是和原輸入的 $x_i$ 一樣時輸出 0，再用**或運算**串起來。

最大項 (maxterm) : 在有 $n$ 個變數的布林函數中，一個**包含所有變數**的**和項 (OR term)**，就稱為最大項。同樣地，每個變數都必須出現恰好一次。即找輸出為 **0** 的組合，用 **OR** 連起來（**$0$ 是原貌，$1$ 是補項**）。

>[!question] 可不可以化簡邏輯運算式 (Logic expression) 所需的運算元 ?
>這問題的一個思路是可不可以用 $\{\text{AND}, \text{NOT}, \text{OR}\}$ 內的幾個元素構出 $\{\text{AND}, \text{NOT}, \text{OR}\}$ 。我們可以用 $\{\text{AND}, \text{NOT}\}$ 構出 $\{\text{OR}\}$ 具體操作如下 $$A \lor B = \overline{\overline{A \lor B}} = \overline{\overline{A} \land \overline{B}}$$ 類似的操作，我們可以用 $\{\text{OR}, \text{NOT}\}$ 構出 $\{\text{AND}\}$ 具體操作如下 $$A \land B = \overline{\overline{A \land B}} = \overline{\overline{A} \lor \overline{B}}$$
