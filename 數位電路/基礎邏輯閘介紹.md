# 常見邏輯閘
### Identity gate (Buffer gate)

![[Identity_gate.png]]

>[!question] 為何要設計 Identity gate ，它啥都沒幹阿 ?
>解決系統缺陷
>1. 訊號放大與推動力 : 訊號隨著跑的距離增加，它的電壓跟電流會減小，需要 Identity gate 把它放大回原來大小。
>2. 減速帶 : 讓長度較短的導線經過 identity gate 減速一下等較長的導線的信號抵達，或是不讓一個信號跑太快影響到前面的信號。

>[!note] 總結
>在 [[積項之合與合項之積]] 中已經闡述我們只需要 AND、OR、NOT 就可以在任意給定的輸入與任意輸出之下，造出一個由 AND、OR、NOT 組成的判斷式來表達輸出和輸出之間的映射，**其實只輸要 NAND 就能 AND、OR、NOT**。可以觀察如果在輸出端加上一個叫 Inversion Bubble 的小圓圈，其結果會反過來，工程師用 inversion bubble 來代替較難畫的 not gate 。

>[!question] 為啥我們還需要 NAND、NOR、XOR 等 ? 
>NAND 跟 NOR 都可以單獨當 universal gate set ，至於 XOR 是在抽象層很好用，常見用是
>- 二進位加法
>- 判斷相異性
>- $A \oplus X \oplus X =A$ : 這在加密時很好用，發送方把明文 ($A$) 可以跟密鑰 ($K$) 做一次 XOR，別人看不懂，但接收方把收到的 $A \oplus K$ 再跟密鑰 ($K$) 做一次 XOR ，就變回 $A$ 。
>- 位元翻轉 : 跟 1 做 XOR 會把該位元翻轉，跟 0 做 XOR 會把讓位元保持。


>[!question] 實務上為啥主流用 NAND 而不用 NOR ，兩者都可以當 universal gate set ?
>NAND 是數位電路的萬用積木，因為它在實體硬體上速度最快、面積最小、最省電

# Universal gates
用 universal gate set 就可以造出所有的邏輯閘。最簡單的 universal gate set 是 $\{\text{AND}, \text{NOT}, \text{OR}\}$ ，過來衍伸出 $\{\text{AND}, \text{NOT}\}$ 跟 $\{\text{NOT}, \text{OR}\}$ ，最後集大成是 $\{\text{NOR}\}$ 跟 $\{\text{NAND}\}$ 。
