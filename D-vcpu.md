# Solved problem
Hypervisors implement virtual PMU (vPMU) interfaces to expose hardware monitoring capabilities to guest VMs.
- substantial runtime overhead during profiling operations
- compromising measurement accuracy
- compromising fidelity of performance characteristics.

>[!question] What causes these overhead
>- KVM employs a trap-and-emulate approach to intercept on the VM's access to PMU MSRs.
>- KVM employs complex emulation logic to properly isolate physical PMU resources between VMs and the host.
>- KVM’s approach to virtualizing Performance Monitoring Interrupts (PMIs), the interrupts generated by the PMU, introduces significant latency in interrupt delivery to VMs.
