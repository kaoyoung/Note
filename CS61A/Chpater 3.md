# Section 3.3 (Exceptions)

>[!note] 概念一
> The Python interpreter raises an exception each time it detects an error in an expression or statement. Users can also raise exceptions with `raise` and `assert` statements.

Exception 有兩個來源，一個是直譯器偵測到問題時，另一個是程序員自己用 `raise` 或是 `assert` statement 做出來的。
