# an epsilon of room
出自陶哲軒的文章[give yourself an epsilon of room](https://terrytao.wordpress.com/2009/02/28/tricks-wiki-give-yourself-an-epsilon-of-room/)，這方法並非他提出的，他單純總結俠。
> [!tip] an epsilon of room的想法概括
> 假设我要研究一个对象$x_0$，以及与这个对象有关的一个数学命题$S_0$，我们这样一组对象简写为$(S_0,x_0)$。但是我们无法直接理解$x_0$这个对象，我们缺乏直接对$x_0$进行操作从而解决与之相关的$S_0$的技术和条件。不过我们发现一个我们已经很好地理解的一系列对象$x_{\varepsilon}$，关于$x_{\varepsilon}$也有一个类似的命题$S_{\varepsilon}$，我们把这一组对象简写为$(x_{\varepsilon},S_{\varepsilon})$。
> 
> 这个时候，如果$(x_{\varepsilon},S_{\varepsilon})$恰好是一个足够好的对象，以至于我们可以从$$(x_{\varepsilon},S_{\varepsilon})\forall \varepsilon\implies (x_0,S_0)$$那么原来的问题也就解决了。

- 想法是先把條件放鬆($\epsilon$空間)看有啥好結論，最後在收縮回去只要 $\epsilon$ 可以任意小，那在條件放鬆時的結論，也可套回原問題。 
所以總的來說想法是

> [!tip] 想法1.1.2
> 如果我们有一个对象$x$，它可以表达为某个序列$x_n$的极限。如果我们要研究$x$的某个性质，我们不妨研究$x_n$这个序列的有关性质。
### **舉些例子**
#### **例子一**
先定義$a_n := \sum^{n}_{k=0} \frac{1}{k!}$ ，那$\lim_{n \to \infty} a_n$是否小於一個實數。證明的一個方式是用以下不等式切入
$$
\sum^n_{k=0} \frac{1}{k !} < 1 + \frac{1}{2} + \frac{1}{2^2} + \cdots + \frac{1}{2^{n-1}} \leq 2
$$
最後才說$\lim_{n \to \infty} a_n \leq 2$。**這證明只在開頭和結用到$\lim$，中間操作的都是$a_n$，因為在操作的對象是$(x_{\epsilon}, S_{\epsilon})$，只有在開始時需要說在討論極限，結尾時需要回到極限。**
#### 例子二
如果$a_n \to a, b_n \to b$ 且$a,b \in \mathbb{R}$ 那 $a_n b_n \to ab$。在這邊的證明是用
$$
\left| a_n b_n - ab \right| = \left| a_n (b_n - b) + (a_n - a)b \right| \leq a_n  \left| (b_n - b) \right| + b \left| (a_n - a) \right|
$$
可以看到先將條件放鬆，在說明放鬆可以任意小。
#### 例子三
**參考自pichachu345的"Re0微积分1：用牛顿迭代法求算术平方根"**

>[!question] 
>假設 $a >0$ 定義序列 : $$x_{n+1} := \frac{1}{2} \left( x_n + \frac{a}{x_n} \right)$$
>1. 證明在 $x_1 > 0$ 的條件下 $x_n \to \sqrt{a}$ 。
>2. 估計絕對誤差 $e_n := x_n - \sqrt{a}$, 給出 $\left| e_n \right|$的上界估計。

>我們無法直接回答$\sqrt{a}$在它為無理數下的有理數數值表示，所以我們造了數列 $\{x_n\}$，只要$x_1$ 為有理數那數列$\{x_n\}$為一有理數數列。這數列可以逼近到$\sqrt{a}$，也就是要多小有多小。

只要說明$\{ x_n \}$為遞減且有下界數列，那它有極限。它有極限後假設它$x_n \to x$那$$ x = \frac{1}{2} \left( x + \frac{a}{x} \right) \Rightarrow x^2 = a \Rightarrow x = \pm \sqrt{a}$$顯然$x_n > 0$ 因為 $x_1, a > 0$，所以 $x = \sqrt{a}$。最後說一下 $x_n, n > 1$ 有下界由 $$\frac{1}{2} \left( x_n + \frac{a}{x_n} \right) \geq \sqrt{a}$$ 可以看出；$\{x_n\}$ 遞減由 $$ \frac{x_{n+1}}{x_n} = \frac{1}{2} \left(1 + \frac{a}{x^2_n} \right)$$ 和 $x_n \geq \sqrt{a}, n > 1$可以看出。
 在這例子中你可能好奇 $\epsilon$ 在哪? 
 -  $\epsilon$ 應該要抽象的想成一個誤差(放鬆)的區間
 有了誤差的區間，我們**想問誤差可以無限小嗎**? 如果可以兩者可以視為大致上一樣的東西，在這邊的記號上是 $x_n \to \sqrt{a}$ 。說一下這邊的誤差估計吧，定義誤差$e_n := x_n - \sqrt{a}$ ，那麼有$$\frac{e^2_n}{2 x_n} = \frac{x^2_n - 2 x_n \sqrt{a} + a}{2 x_n} = \frac{1}{2} \left( x_n + \frac{a}{x_n} \right) - \sqrt{a} = e_{n + 1}$$ 所以 $$\left| e_{n+1} \right| \leq  \frac{1}{2 x_n} \left( \frac{ \left| e_1 \right| }{2 x_n} \right)^{2^{n}}  \leq  \frac{1}{2 \sqrt{a}} \left( \frac{\left| e_1 \right|}{2 \sqrt{a}} \right)^{2^{n}}$$
 >[!question] 
>假設 $a >0$ 定義序列 : $$x_{n+1} := \frac{1}{k} \left( (k-1) x_n + \frac{a}{x^{k-1}_n} \right)$$
>證明在 $x_1 > 0$ 的條件下 $x_n \to a^{\frac{1}{k}}$ 。
 
 先說明該極限存在。先證下界存在，由算幾不等式我們有$$\frac{1}{k}\left((k-1)x_n + \frac{a}{x^{k-1}_n} \right) \geq a^{\frac{1}{k}}$$接下來證明他是遞減函數即可$$\frac{x_{n+1}}{x_n} = \frac{1}{k}\left((k-1)x_n + \frac{a}{x^{k-1}_n} \right)\frac{1}{x_n} = \frac{1}{k} \left(k-1 + \frac{a}{x^k_n}\right) < \frac{1}{k} (k-1+1) = 1 \text{ if $x_n \neq a^{\frac{1}{k}}$}$$因為極限存在，我們令他為 $x$ 其值由等式知$$x = \frac{1}{k} \left( (k-1)x + \frac{a}{x^{k-1}} \right) \Rightarrow x^k = a \Rightarrow x = a^{\frac{1}{k}}$$
>[!question]
>算幾不等式的推廣證明給一下

思路為先把連乘用 $\log$ 換成連加，即$$\log \left( (x_1 \times\cdots \times x_n)^\frac{1}{n}\right) = \frac{1}{n} \left( \log x_1 + \cdots + \log x_n \right)$$接下來注意到 $\log$ 是 convex 函式所以用 Jenson inequality，Jenson inequality 為$$f(ta + (1-t)b) \geq tf(a) + (1-t) f(b)$$只有在 $a=b$ 時等號成立。用完 Jenson inequality 我們有$$\log \left( \frac{1}{n}(x_1 + x_2 +\cdots + x_n) \right) \geq \frac{1}{n} \left( \log x_1 + \cdots + \log x_n \right) = \log \left( (x_1 \times\cdots \times x_n)^\frac{1}{n}\right)$$最後因為 $\log$ 為遞增函數，我們可以確定$$\frac{1}{n}(x_1 + x_2 +\cdots + x_n) \geq (x_1 \times\cdots \times x_n)^\frac{1}{n}$$須注意 $x_i$ 為非負實數。
