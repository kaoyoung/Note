### Package Explanation

Nav2 utilizes behavior trees to invoke modular servers to accomplish an action. These actions can involve
- Path computation
- Control force
- Recovery
- Other navigation-related operation
![[Pasted image 20251111230015.png]]
**Major** : BT Navigator Server: This service organizes and invokes the following three minor services.
**Minor** : 
1.  **Planner Server:** Responsible for path planning
2.  **Controller Server:** It controls the robot’s movement based on the planned route.
3. **Recovery Server:** The recovery server handles unknown or faulty conditions autonomously.

### Different Map

**Motivation :** During robot navigation, relying solely on the original map generated by SLAM is insufficient since the environment is dynamic and the original map is static.
##### Global Costmap: (Planner Server)
It is mainly used for global path planners. It typically includes the following layers: 
1. Static Map Layer : The static map usually created by SLAM.
2. Obstacle Map Layer : Dynamically record obstacle information perceived by sensors.
3. Inflation Layer : This layer inflates (expands outward) the maps from the previous two layers
##### Local Costmap: (Controller Server)
The local costmap is primarily used for the local path planner. It typically consists of the following layers:
1. Obstacle Map Layer: This layer records dynamically sensed obstacle information from sensors.
2. Inflation Layer: This layer inflates (expands outward) on top of the obstacle map layer to prevent the robot’s shell from colliding with obstacles.
