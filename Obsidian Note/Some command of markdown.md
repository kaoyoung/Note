### 为什么要有三种符号？

这主要是为了**方便和灵活性**：

1. **个人偏好**：有些人可能觉得按 `-` 键比 `*` 键更顺手。
    
2. **嵌套列表**：在创建多级列表时，可以使用不同的符号来区分层级，让源代码看起来更清晰。

    <dl>
      <dt>子术语 A</dt>
      <dd>子术语 A 的解释。</dd>

```
    </dl>
  </dd>
</dl>
```
1. **`<dl>`**：**Definition List（定义列表）**
    
    - **角色**：整个定义列表的**总容器**。
        
    - 就像 `<ul>` 是无序列表的容器一样，`<dl>` 包裹所有相关的术语和解释。
        
2. **`<dt>`**：**Definition Term（定义术语）**
    
    - **角色**：用来标记**需要被解释的术语、名词或标签**。
        
    - 它通常以粗体显示，并且独占一行。
        
3. **`<dd>`**：**Definition Description（定义描述）**
    
    - **角色**：对应术语的**具体解释、描述或内容**。
        
    - 它默认会带有一定的**左缩进**，清晰地与上方的术语区分开。
