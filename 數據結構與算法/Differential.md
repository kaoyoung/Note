# 一維差分
## 動機
我們想在一個一維數列(arr)內框定多個範圍(\[$i_1$,$j_1$\]、\[$i_2$,$j_2$\]、$\cdots$)，並在這些範圍內分別增加一個固定的性值，最後在加完這些性值後，整個arr變成整樣?
#### 舉個例子 :
給個數組\[0, 0, 0, 0, 0, 0\]範圍\[1, 3\]跟\[2, 4\]內都加一，最後數組是啥?
答案是 : \[0, 1, 2, 2, 1, 0\]
## 思考過程
### 先思考單一個區間的情況
暴力法是統一在\[i,j\]內用遍歷整個區間的方式來更新，但這方法有沒有可能在O(1)內達成? 在[[prefix sum]]中提供了一個求區間內性值的思路，固定一個不在\[i,j\]內點(p)並記錄兩件事(假設p < i)
1. p到i的性值變化
2. p到j的性值變化
然後用下面式子來做計算
$$
\text{Property p to j} - \text{Property p to j} = \text{Property i to j} \text( 式一)
$$
- 注意p點只要不在\[i,j\]內就行。
- 式一可以用做更新完所有性值後的逆運算。
如果把區間大小縮為1就可以得到算出每個元素最後的值，如式二所示
$$
\text{Property p to k} - \text{Property p to (k-1)} = \text{Property at k} (式二)
$$
從式二這個逆運算可以知道，對於每個下標所對應增加的性值都要原封不動的加上去。
舉個例子，你要在\[0, 0, 0, 0, 0, 0, 0\]中\[1, 3\]都加一，正運算後的數組為
- \[0, 0, 1, 2, 3, 3, 3, 3\] (這邊先右移一位，並將開端用0儲存)
逆運算後變為
- \[0, 1, 1, 1, 0, 0, 0\]
>[!思路問題]
>用前綴和的方式去得到每個值最後的樣態，你必須要每個下標對於每個經過的性值都要處理，那跟暴力法別無二致。**根本沒用到區間內增加的性值都一樣這特性**。

>[!核心思路 (積分思路)]
>從一個固定點($p_1$)開始向右移動到($p_2$)，你要如何表達$p_2$? 第一個思路是直接看$p_2$是多少；第二個思路是看$p_1$到$p_2$之間的變化量($\Delta p$)，最後用$p_1$ + $\Delta p$。第二個思路可以更好的用到**區間內增加的性值都一樣這特性**，因為在這區域內$\Delta p = 0$，所以只需在開頭和結尾紀錄變化量就行。開頭為性值變化的開始，需要紀錄這個性值變化；結尾為性值變化的結束，需要紀錄性值變化回原本狀態的差。

舉個例子，你要在\[0, 0, 0, 0, 0, 0, 0\]中\[1, 3\]都加一，用積分思路後記錄的數組變為
- \[0, 1, 0, 0, -1, 0, 0\] 
結果變為
- \[0, 1, 1, 1, 0, 0, 0\]
### 面對多個區間
單純延伸單一區間的想法。在每個要更新的區間的開頭和結尾都記錄性值變化差
### 跟prefix sum的差距在哪?
他們想問的事情本質就不同
- prefix sum : 數組已給定，你不需要更新他們的狀態。
- differential : 你需要更新他們的狀態好幾次。
看待問題的角度也不同
- prefix sum : 給定一個錨定點，從錨定點開始累積每個單位時間的狀態差，依靠**微分思路**(aka 相減)推出不同時間點之間的狀態差。
- differential :單純記錄每個單位時間的狀態差。可以依靠**積分思路**(aka prefix sum)得到各時間的狀態。

# 二維差分
### 參考自[靈神題解 : 一維差分到二維差分](https://leetcode.cn/problems/stamping-the-grid/solutions/1199642/wu-nao-zuo-fa-er-wei-qian-zhui-he-er-wei-zwiu)
## 動機 
我們可以在一個長方形內，對一個個子長方形，各自增加某一性質，這性質必須要遍及該子長方形，且對其內的元素該性值增加幅度要相同。最後要輸出原長方形，在經過這些增加性質的操作後的模樣。
## 思考過程 
在一維差分上，我們紀錄數組在每個元素開始跟結尾的性值變化差。那在二維差分是否有相同思路來處理，有的兄弟有的見下圖(圖來源 : [【图解】从一维差分到二维分(Python/Java/C++/Go/JS/Rust)](https://leetcode.cn/problems/stamping-the-grid/solutions/1199642/wu-nao-zuo-fa-er-wei-qian-zhui-he-er-wei-zwiu))
![[2D Differential demonstration.png]]
我們可以將最右下角的值當

說一下對於上圖的理解，跟一維差分一樣是紀錄變化差，兩者的差別來自於差的基準在哪?
- 一維 : 差的基準為前一個值
- 二維 : 差的基準為左前一個值、上面一個值和左上一個值
#### 為何會有著麼多來源? 
根本的原因為你在表示變化量時會從該點延伸到該長方形的右下角

先備知識 : 
- 長方形可以依靠對角線的兩個點去定位。這邊我們統一用左上和右下角去框正方形。
用數學式來看吧 :  想改\[(l1, u1), (r1, b1)\]這區間。最右下角用(rend, bend)來表達。
$$
\text{property [(l1, u1), (r1, b1)]} = \text{property [(l1, u1), (rend, bend)]} - \text{property [(r1+1, u1), (rend, bend)]} - \text{property [(l1, b1+1), (rend, bend)]} + \text{property [(r2+1, u2+1), (rend, bend)]}
$$
## 順序的影響
在一維差分中，順序定義是很自然的事情因為一共就兩個方向，但在二維差分中，你可能的方向共有四個，因為有row-major和column-major而這兩個又各有2個方向。另外還有一個問題是，要用哪幾個元素，更新下一個元素? 先回答方向吧，因為你要從左上走到右下，所以你的方向必須是，從左到右、從上到下，至於row-major還是column-major都行，這是為


對於要用哪幾個元素更新元素，其實從我們造二維差分的式子可以看出來
$$
\text{property [(l1, u1), (r1, b1)]} = \text{property [(l1, u1), (rend, bend)]} - \text{property [(r1+1, u1), (rend, bend)]} - \text{property [(l1, b1+1), (rend, bend)]} + \text{property [(r2+1, u2+1), (rend, bend)]}
$$
