# 想法
給定一數組$(x_1, x_2, x_3, \cdots, x_k)$ 和一區間$(l,r)$，想求這一區間內所有元素某一性質的總和，只要該元素符合以下等式
$$
 f(x_l + x_{l+1} + \cdots + x_r) = f(x_1 + x_2 + \cdots + x_r) - f(x_1 + x_2 + \cdots + x_{l-1})
$$
我們便可以藉由紀錄從$x_i$到$x_i, i=1,2,\cdots$ 的總和迅速得知$f(x_l + x_{l+1} + \cdots + x_r)$，因為上式的右邊兩項都從$x_1$開始。上面這等式不一定成立，三角不等式即是個很好的反例。
> **抽象 :**
> 給定一錨點，用這錨點和兩未知數分別的關係，簡化探討兩個未知數之間關係的難度，類似分析常用的2$\epsilon$ 證明，用錨點搭起橋樑。其實平常在算$a-b$即是用0當錨點，現在平移它。
# 實踐
- **子數組總和** : 可擴展成給定一數線上任兩點的位置求距離差，可以用0當錨點等同於$a-b$，或是其他好計算的標的，該標的常出現在兩端，因為這樣才能提供給所有人當信標。
- **最大子數組合** : 原本的思路是找出一對(subarr1、subarr2)從$x_0$開始的數組和($x_0$表示空集合)，其中subarr2是subarr1的子集合，而這對數組和的差構成出最大子數組合，求出的方法是枚舉所有可能，即在數組中任挑兩位置。其實可用枚舉右維護左的思路去做，右邊負責探索可能，左邊利用貪心的想法保證解在正確的路上。能利用貪心是因為要減去subarr2，所以subarr2越小越好，可以無腦的再看到比較小者直接帶走。
