# 觀察

題目要求常是數組或是某個連續的區間和問題本身具有單調的特性。如何在符合第一個限制下，用第二個特性來縮小解範圍。

---
# 說明 
## 一般情況 
注意到符合某個連續的區間的可能性有$\frac{n^2}{2}$ (假設可以自己到自己)種可能，這給了我們子數組問題的遍歷時間上界。如果題目所要求答案符合的規則不夠強時，我們要看的解空間會變大，像是如下題目 (Q1):
> Q1 : 給定一數組，裡面的值可以有正有負，求在子數組之和要小於K的限制之下，最大的子數組長度?
> A1 : 如果數組裡面的值均正為一個簡單的滑動窗口題，時間$O(n)$。如果在有負的情況下還用滑動窗口會炸開，因為負數可讓子數組變長的同時子數組之和下滑，這是在數組內的值均正時達不到的效果。這邊可以發現有負時考慮的解空間邊大，我們有兩方案去處理這問題，一個是砸記憶空間去紀錄過去的事，好讓重複的事減少，或是砸時間。這題的解法在常見問題1的Q回答。
## 問題本身具有單調的特性
回顧窮舉所有可能情況的過程，假設從1到n，大致流程如下
```c
for(int i=1; i<n; ++i){
	for(int j=i; j<=n; ++j){
		// do something	
	}
}
```
如果問題存在某種單調性第二層的for循環根本不必遍歷到n，只需到條件爆開的地方停下(假設停在x1)即可，接著第一層的for迴圈一樣依靠單調性知道，i到x1-1是服和條件的，那i+1到x1-1也是自然服和條件的，但i+1到x1-1的解必不如i到x1-1，所以i+1直接從x1開始考慮，換句話說第二層for迴圈可直接從x1進場。寫成如下模板
```c
int right = 1;
for(int i=1; i<n; ++i){
	for(int j=right; j<=n; ++j){
		if(test(right)){ // test the input is valid or not
			// update max or min number
			// ++right;
		}
	}
}
```


用下面這例子(Q2)去思考

> Q2 : 給定一數組，裡面的值均正，求在子數組之和要小於K的限制之下，最大的子數組長度?
> A2 : (暴力解) 第一層for迴圈提供起始的i值。 在第二層的for測從i開始最大的子數組長度，方法為一路加下去，加完後問符不符合條件，符合的話更新最大的子數組長度。

**改進暴力法 :**
第二層for環圈只需加到子數和爆掉為止(假設加到x1)，因為在加下去只會更大也不符合條件，接這再回到第一層for迴圈更新起始位置，而第二層for環圈從x1開始測試。

```python
    for right in range(n):
        # 1. 進窗口 (Add)

        # 【設定 2】: 決定 while 的條件
        # 求最長：當窗口「變壞 (Invalid)」時 -> 縮
        # 求最短：當窗口「變好 (Valid)」時   -> 縮
        while ( 觸發縮圈的條件 ):            
            # 【設定 3a】: 求「最短」在這裡更新答案 (因為此刻是合法的)
            # if 求最短: ans = min(ans, right - left + 1)

            # 3. 出窗口 (Remove)
            window.remove(nums[left])
            left += 1

        # 【設定 3b】: 求「最長」在這裡更新答案 (因為縮完後，窗口恢復合法)
        # if 求最長: ans = max(ans, right - left + 1)
        
    return ans

```

# 枚舉左還是右?
回顧**窮舉過程**中的雙層for迴圈似乎是在枚舉左維護右，但在後面談及他的優化時，整個過程可以拆解為先給定左端點，右端點從左端點開始衝，衝到底後，左端點開始向前縮，縮到極限(條件不符合或是碰到右端點)後，右端點再衝，左再縮，如此反覆循環。整體來看是
- 先給左(只給初始點)→右衝→左縮→右衝→左縮→...
因為一開始給左只給初始端點沒用途，所以過程視為
- 右衝→左縮→右衝→左縮→...

才合理，因此整體視為**枚舉右維護左**。其實**枚舉左維護右**跟**枚舉右維護左**在條件是單調時是相同的，兩者只是看問題的順序不同，參考如下說明

>細看**枚舉左維護右**跟**枚舉右維護左**這兩操作都是圍繞在一個連續的位置上，所以我們只要在乎頭跟尾有沒有被掃到就好。**枚舉左維護右** 的過程是從給定的要判斷輸入的尾端掃回前面，左邊進入窗口，右邊出窗口；另一方面，**枚舉右維護左** 的過程是從給定的要判斷輸入的前端掃回後面，右邊進入窗口，左邊出窗口，我們要說的是兩者看的頭尾是否相同在假設條件是單調的情況之下。證明的一條路子是他們出來的解都是正確的而正確答案唯一，所以兩者相同，這是用答案來構建兩者的橋樑。我想直接構出兩者的關係使用互相包含的說明如下

- 對於任何由「枚舉左維護右」產生的窗口$(l_1, r_1)$，由於單調性，當我們使用「枚舉右維護左」掃描到右指針$r_1$ 時，左指針$(l^{\prime}_1)$不可能在$l_1$ 的右邊，不然$(l^{\prime}_1, r^{\prime}_1)$ ($r^{\prime}_1$ 為 $r_1$ 前一輪掃的點)是一個解，即「枚舉左維護右」根本不會取$(l_1, r_1)$，矛盾，所以左指針$(l^{\prime}_1)$在$l_1$ 的左邊，這時會開始進行「枚舉右維護左」的維護流程，因為取的範圍大於$(l_1, r_1)$。
- 反之，對於任何由「枚舉右維護左」產生的窗口，用跟上面一樣的邏輯去證。因此，兩種方法在單調條件下會覆蓋相同的窗口集合，從而等價。
>因此兩方法等價，只是遍歷的順序不同。

# 常見問題
1. 找合 : 須確保每個值均正，如果有負的遞增特性會消失，可用折線圖做更直覺得思考。**有副食如何求解，即問如下問題
 >Q : 給定一數組，裡面的值有正有負，求在子數組之和要小於K的限制之下，最大的子數組長度?
2. 左、右指針代表函義要想清楚，它們會影響邊界條件和判斷數量。
3. 找頻率
4. 再找最大(最小)值，一開始常設該紀錄值為INT_MAX(MIN)，須注意如果題目無符合條件的解的情況，不如會直接輸出INT_MAX(MIN)。

# 總結
用問題的單調性減小可能解空間，類似於**剪枝**操作。
