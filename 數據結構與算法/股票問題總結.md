這類問題大致可以分為兩類，第一類為「**不限制**購買次數」，第二類為「**限制**購買次數」。
## 不限制購買次數
代表題目如下
- [122. 买卖股票的最佳时机 II](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/)
- [714. 买卖股票的最佳时机含手续费](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/)
- [309. 买卖股票的最佳时机含冷冻期](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/)

這邊的思路都是一致的 ([309. 买卖股票的最佳时机含冷冻期](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/)稍微不一樣) 。因為股票都只有一種，所以狀態只有持有跟未持有兩種，如果有 n 種股票那其狀態有 $2^n$ 個（這不在考慮範圍），而且一個特定天的兩個狀態（持有跟未持有）可以從前一天的兩個狀態（持有跟未持有）給推出來，因此可以用 dynamic programming 的思想來處理，用前一天的兩個狀態來推今天的兩個狀態。裡面要注意的是 [309. 买卖股票的最佳时机含冷冻期](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/)  這一題，因為有冷凍期在其中干擾。關鍵解題點在於冷凍期只是規定當前的買要在前一次賣的兩天後，轉移狀態只是多考慮成前兩天，或是在前一天的狀態加上冷凍期。

>[!Note] dynamic programming 跟 divide and conquer 思路差別
>dynamic programming 是切成有重疊 (會重複計算到的) 的子問題，所以需要把這些子問題的解存起來避免重複計算，而這些子問題是**最優子結構** (當一個問題的最優解包含其子問題的最優解時，就稱該問題具有最優子結構)，所以可以由這些子問題的解構造出原問題的解；divide and conquer 是切成不相關的子問題，再由這些子問題的解拼出原問題的解。

## 限制購買次數
代表題目如下
- [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)
- [123. 买卖股票的最佳时机 III](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/)
- [188. 买卖股票的最佳时机 IV](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/)
- [3573. 买卖股票的最佳时机 V](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-v/)

思路跟前一大類類似只是多了買賣次數的限制，一個顯然的思路是加上一個股票購買次數的維度。這思路是對的，只是最後在求最大值需要遍歷所有購買次數的值，是否存在一個不用遍歷所有購買次數的值的構造方式? 這個構造方式是加上的維度是**最多**股票購買次數，有了最多這個詞限制之後，求最大值只要看「購買次數極限那個值」就好。
注意: **最多**股票購買次數同樣可以由小一次購買次數那一邊推過來，所以 dp 思路依舊可通。
