# 常用名詞
- object
原文: 
```text
region of data storage in the execution environment, the contents of which can represent values
```
在執行期中，一個儲存資料的地區。

- storage duratinos of objects
```text
An object has a storage duration that determines its lifetime. There are three storage durations: static, automatic, and allocated.
```
- 說明
	- static storage duration: 程式**一啟動時就被分配**，直到程式**結束時才銷毀**。通常存放在 Data 段或 BSS 段。
	- automatic storage duration: 物件在進入特定的程式區塊（通常是 `{ }` 括號）時出生，**離開括號時立刻自動消失**。存放在 **Stack（堆疊）**。
	- allocated storage duration: 物件的生死完全由程式設計師決定。存放在 **Heap（堆積）**。

- `void *` 之謎
`void *` 的出現是為了讓開發者**顯示 (explicir) 或 強制轉型**，來讀取最終物件所設計的，否則編譯器會報錯。須注意轉換的型別要相容，否則會 undefined behavior 如下所示
```text
A pointer to a function of one type may be converted to a pointer to a function of another type and back again; the result shall compare equal to the original pointer. If a converted pointer is used to call a function whose type is not compatible with the pointed-to type, the behavior is undefined.
```
我們不能保證 `void *` 之間的轉換是正確的，如果轉換型別彼此是不相容那結果是未定義行為。

1. byte string: 使用 char 作為最小操作單位，每個 char 至少要 8 bits，

- `(*(void(*)())0)();`、`void **(*d) (int &, char **(*)(char *, char **));`
```c
(*(void(*)())0)();
```
上面這指令似乎難以理解，我們換個指令吧
```c
typedef void (*funcptr)(); // this is a function pointer
(* (funcptr) 0)();
```
上面這程式是將 0 轉換成一個函數指針並取值後開始運作，這程式的函數指針是一個不確定參數個數並輸出 void的函數指針 (要表明無參數要用 `void`)。
`void **(*d) (int &, char **(*)(char *, char **));` : 
- This function returns a pointer to a pointer to void
- d : is a function pointer that takes two parameteres:
	1. a reference to an int
	2. a function pointer that returns a pointer to a pointer to a char and takes two parameters. One paramter is a pointer to a char and the other is a pointer to a pointer to char.

- `void (*signal(int, void (*)(int)))(int);`
`signal` 是一個轉運站。你給它一個編號（int）和一個技工（舊的處理函數），它處理完後，會還給你另一個技工（舊的處理函數的指針）。
```c
// 1. 先定義什麼是「技工」（處理函數指針）
typedef void (*Handler)(int);

// 2. 現在 signal 的宣告變成了人話
Handler signal(int sig, Handler func);
```
